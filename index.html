用中转站会被 OpenAI 封号吗？
正规官转站（OpenRouter/YesCode/oaipro）从 OpenAI 官方渠道采购 API，和你直连完全一样。OpenAI 封的是违反 ToS 的行为，不是正常 API 调用。判断依据：拿到 sk- 开头的 Key → 官转。
为什么中转站比官方还便宜？
正规站的便宜来自批量采购折扣、Prompt 缓存套利、Batch API 套利。价格低到官方 0.3 折以下大概率是逆向账号拼车或模型掉包。
充了钱中转站跑路了怎么办？
降低风险：1) 单次充值 ≤ ¥200；2) 用光再充不囤余额；3) 1主+2备不依赖一家；4) 运营<6个月的站跑路概率最高。本站不卖 Token，仅提供中立评测。
用中转站能用 Claude 吗？
目前官转站仍可用（通过海外实体采购）。Anthropic 反制在加强。兜底：DeepSeek V4 性能接近 Claude，¥3-6/百万Token；通义千问 Qwen3.6 免费额度充裕。
