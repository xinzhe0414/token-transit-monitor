常见问题
用中转站会被 OpenAI 封号吗？
正规官转站（OpenRouter/YesCode/oaipro）从 OpenAI 官方渠道采购 API，和你直连完全一样。OpenAI 封的是违反 ToS 的行为（非支持地区直连 + 逆向账号），不是正常 API 调用。判断依据：你拿到的是 sk- 开头的 Key → 官转。
为什么中转站比官方还便宜？
正规站的便宜来自批量采购折扣、Prompt 缓存套利（重复 System Prompt 官方半价）、Batch API 套利（非紧急请求打包走 Batch，官方 5 折）。如果价格低到官方 0.3 折以下，大概率是逆向账号拼车或模型掉包。
哪个站延迟最低？
一般规律：香港节点（30-80ms）< 日本/新加坡（60-150ms）< 美国（200-400ms）。本站推荐：oaipro（香港）、YesCode（日本）、OpenRouter（美国，最稳定）。实际延迟和你本地网络有关，建议各站都试一下。
怎么确认中转站返回的是真模型？
用 hvoy.ai 在线验证，或手动测试：1) 问"用中文重复我说的话"→ Qwen 会逐字重复，Claude 会先理解再转述；2) 写代码任务 → Claude Opus 的代码质量明显更高。本站评测表标注了每家站的模型真伪状态。
充了钱中转站跑路了怎么办？
降低风险：1) 单次充值 ≤ ¥200；2) 用光再充，不因优惠充年卡；3) 1 主 + 2 备，不依赖一家；4) 运营 < 6 个月的站跑路概率最高。本站不卖 Token，只提供中立评测。
用中转站能用 Claude 吗？
目前官转站仍可用（通过海外实体采购）。但 Anthropic 反制力度在加强。兜底：DeepSeek V4 性能接近 Claude，¥3-6/百万 Token；通义千问 Qwen3.6 免费额度充裕。
